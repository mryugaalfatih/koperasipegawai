# Alur Presentasi Demo

## Pembukaan

KoperasiPro adalah rancangan sistem koperasi simpan pinjam berbasis web untuk admin/pengurus dan mobile app untuk anggota. Demo awal ini menunjukkan dashboard operasional, rancangan modul, database Supabase, dan kesiapan pengembangan ke aplikasi anggota.

## Cerita Demo Web Admin

1. Dashboard menampilkan kesehatan koperasi dalam satu layar:
   - Total anggota aktif.
   - Saldo simpanan.
   - Portofolio pinjaman.
   - Estimasi SHU berjalan.

2. Pengurus dapat melihat laporan laba rugi berjalan:
   - Pendapatan jasa.
   - Beban operasional.
   - SHU sebelum pajak.

3. Bendahara/operator mengelola arus kas:
   - Simpanan masuk.
   - Angsuran pokok.
   - Jasa pinjaman.
   - Pencairan pinjaman.
   - Biaya operasional.

4. Komite pinjaman melihat antrian pengajuan:
   - Menunggu survei.
   - Siap komite.
   - Dokumen kurang.

5. Laporan siap dikembangkan ke format resmi:
   - Rekap simpanan.
   - Aging tunggakan.
   - Buku besar.
   - Laba rugi.
   - SHU.

## Cerita Mobile Anggota

Mobile app menjadi kanal komunikasi anggota:

- Anggota login dengan nomor HP/email.
- Anggota melihat saldo simpanan dan mutasi.
- Anggota melihat jadwal angsuran.
- Anggota menerima notifikasi jatuh tempo.
- Anggota mengajukan pinjaman dan upload dokumen.
- Anggota melihat estimasi SHU personal.

## Penutup

Setelah project disetujui, keputusan bisnis yang perlu difinalkan adalah metode bunga pinjaman, formula SHU sesuai AD/ART, format laporan resmi, role pengguna, dan kebutuhan integrasi pembayaran/notifikasi.
